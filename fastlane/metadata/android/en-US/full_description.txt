Mizu is a private, 100% offline video and audio player built with Kotlin and Jetpack Compose. It declares zero internet permissions, contains no ads or trackers, and operates completely on-device.

Supported formats:
 * Audio: Vorbis, Opus, FLAC, ALAC, PCM/WAVE (μ-law, A-law), MP1, MP2, MP3, AMR (NB, WB), AAC (LC, ELD, HE; xHE on Android 9+), AC-3, E-AC-3, DTS, DTS-HD, TrueHD
 * Video: H.263, H.264 AVC, H.265 HEVC, MPEG-4 SP, VP8, VP9, AV1
 * Subtitles: SRT, SSA, ASS, TTML, VTT

Key Features:
 * 100% offline: NO INTERNET permission declared, zero network traffic, zero analytics
 * High performance playback with Media3 engine
 * Audio & subtitle track selection with external subtitle support
 * Swipe gestures for brightness, volume, and seeking
 * Media library with folder and file view modes
 * Playback speed control (0.25x - 4.0x)
 * Picture-in-Picture mode
 * Custom skin system
